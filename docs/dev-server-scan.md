# 沙箱靶机 · 手机扫码预览

开发服务靶机启动后，openLoop 会把靶机地址渲染成二维码，手机扫码即可打开 RN / 移动端页面，
不必手输局域网 IP，也不必依赖流水线终端里的日志。

## 入口

| 位置 | 出现时机 |
| :--- | :--- |
| 看板卡片「扫码」按钮 | 流水线执行中（已分配沙箱）、待人工验收 |
| 视觉验收弹窗「扫码」按钮 | 人工验收门禁，与靶机启停按钮同排 |

弹窗内展示二维码、扫码地址与复制按钮；靶机离线时可直接一键拉起服务。

## 扫码地址来源

1. 优先取流水线 `env-prepare` 节点配置的 `scanUrl` 模板；
2. 未配置时自动使用 `http://<本机局域网 IP>:<靶机端口>`；
3. 模板变量：`{{lanIp}}`、`{{webPort}}`、`{{ports.webPort}}`、`{{task.xxx}}`。

```json
{
  "type": "env-prepare",
  "config": {
    "command": "npx chitu dev --port={{webPort}}",
    "healthUrl": "http://127.0.0.1:{{webPort}}/status",
    "scanUrl": "exp://{{lanIp}}:{{webPort}}"
  }
}
```

二维码在渲染层离线生成（内置编码器，无第三方依赖、无网络请求），点击入口即时呈现。
